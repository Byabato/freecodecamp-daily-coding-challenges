# freeCodeCamp Daily Coding Challenges

A daily practice log of my solutions to freeCodeCamp's Daily Coding Challenges. Each challenge is organized by date and includes an implementation, tests, and concise documentation of the problem-solving approach.

## Goals

- Build consistent problem-solving habits through daily practice.
- Strengthen JavaScript fundamentals and algorithmic thinking.
- Test solutions against examples, edge cases, and stated constraints.
- Document the reasoning and lessons learned from each challenge.

## Repository structure

Each challenge has its own dated folder using this naming convention:

`YYYY-MM-DD-short-challenge-title/`

A challenge folder typically contains:

- `README.md` — problem summary, requirements, approach, complexity, and learning notes.
- `solution.js` — JavaScript implementation.
- `test.js` — automated tests.
- `package.json` — project metadata and test command, when needed.

## Running a challenge

Open the relevant challenge folder in a terminal. For challenges that include a `package.json`, run:

```powershell
npm test
```

You can also use Node.js's built-in test runner directly where configured:

```powershell
node --test
```

Check each challenge's README for its specific requirements and test instructions.

## Approach

I aim to understand the problem before implementing a solution, identify relevant constraints and edge cases, write readable code, run tests, and record what I learned. Solutions are intended for learning and practice, not as production payment-processing or security systems.

Challenges are based on freeCodeCamp's Daily Coding Challenges, including prompts presented through the freeCodeCamp mobile app. Each individual challenge should link to its original source when a stable public URL is available.
